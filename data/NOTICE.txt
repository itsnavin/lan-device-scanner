Reproduce the import from the repository root:
  dotnet run --project tools\UpdateVendors -c Release
This downloads only the two pinned public upstream files, verifies
the data SHA256 and GPL identifier and validates minimum coverage.
It sends no local addresses or device inventory.

To update to a newer snapshot: review an upstream Wireshark release
or official generated manuf snapshot with its retained GPL license,
pin its immutable source revision and independently verified SHA256
in the updater, update this provenance/date/coverage notice, run the
updater, tests and packaging workflow, review the diff and commit
the original data and license together. Updates are explicit,
developer-run operations, never automatic in the desktop app.
